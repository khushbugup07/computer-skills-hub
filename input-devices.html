⌨️ Input Devices

Learn how we give instructions and data to a computer.

What is an Input Device?

An input device is a hardware device used to enter data or instructions into a computer.

Common Input Devices

  • ⌨️ Keyboard: Used for typing letters, numbers and commands.
  • 🖱️ Mouse: Used to point, click, select and move items.
  • 🎤 Microphone: Used to enter sound into a computer.
  • 📷 Webcam: Used to enter images and video.
