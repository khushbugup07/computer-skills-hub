💾 Software Basics

Learn how programs help a computer perform different tasks.

What is Software?

Software is a set of instructions or programs that tells a computer what to do.

Types of Software

  • ⚙️ System Software: Helps operate and manage the computer.
  • 📱 Application Software: Helps users perform specific tasks.

Examples

Web browsers, word processors, media players and operating systems are examples of software.
